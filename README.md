# 雅思备考 App

装在手机上用的雅思备考 App（网页 App，也叫 PWA），目标总分 8：听力、阅读冲 8.5 到 9，写作、口语稳 7、争 7.5。

- 学习：每天的新词和到期复习（记得的词隔 1、3、7、14、30… 天再出现），随时复习（按最近学过、收藏、容易忘的词或按册翻卡）
- 同义替换：154 组题目和原文之间常见的换说法，四选一练习，选错的组会更常出现
- 听音写词：单词拼写，以及听力第一部分常考的姓氏拼读、电话号码、邮编、日期、时间、价格、地址；可以轮换英式、澳式、美式口音
- 听读错题本：做剑桥真题时记下每套的分数（自动换算成雅思分）和每道错题的题型、错因，统计分数主要丢在哪里
- 词汇：学术词表 3 册和话题词 3 册，共 360 个词，每个词有英式音标、中文、英文释义、例句、同义词和同族词
- 写作：大作文五种题型 10 题，每题一篇按 8 分标准写的范文（附段落说明和值得借用的表达）；40 分钟计时写作、字数统计、自查清单，可以复制一段批改提示自己贴给 AI
- 口语：Part 1 的 12 个话题（48 个问题）、Part 2 的 12 张话题卡（准备 1 分钟、说 2 分钟），都有参考回答；录音回放，或者打开发音识别后看词数、语速和重复的词

可以安装到手机桌面，离线使用。发音用的是手机自带的语音。只有“发音识别”需要联网，它默认是关着的。

所有练习材料都是为这个 App 原创的，不包含剑桥雅思真题的内容。

## 文件

| 位置 | 内容 |
|---|---|
| `docs/` | App 本身。发布到 GitHub Pages 的就是这个文件夹 |
| `docs/data/vocab.json` | 词汇，每行一个词条：单词、音标、词性、中文、英文释义、例句、例句中文、同义词、同族词、分类 |
| `docs/data/paraphrase.json` | 同义替换：每组是一个类别、中文意思和几个可以互换的说法 |
| `docs/data/writing.json` | 大作文：题目、范文（按段）、每段的说明、值得借用的表达 |
| `docs/data/speaking.json` | 口语：Part 1 的问题和参考回答；Part 2 的话题卡、参考回答、表达和 Part 3 追问 |
| `docs/js/learn.js` | 学习首页和每日学习 |
| `docs/js/review.js` | 随时复习 |
| `docs/js/spelling.js` | 听音写词：单词拼写和随机生成的数字、字母题 |
| `docs/js/paraphrase.js` | 同义替换练习 |
| `docs/js/mistakes.js` | 听读错题本和分数换算 |
| `docs/js/writing.js` | 范文和计时写作 |
| `docs/js/speaking.js` | 口语练习 |
| `docs/js/lookup.js` | 点词查义：由单词的复数、过去式、-ing、-ly 和同族词找到词条，不依赖页面，可以单独用 Node 测试 |
| `docs/js/srs.js` | 学习记录：每个词的复习阶段和下次复习的日期 |
| `docs/js/recorder.js`、`docs/js/listen.js` | 录音（只在内存里，不上传）和可选的语音识别 |
| `tools/build.js` | 检查数据，生成离线文件清单 `docs/sw.js` 和版本号 `docs/js/version.js` |
| `tools/icons.js` | 生成 `docs/icons/` 里的图标 |

这个 App 的框架来自同一文件夹里的“罗马意大利语 App”。两个 App 发布在同一个网站下时，用不同的存储前缀（`ielts.`）和缓存名（`ielts-`），互不影响。

## 修改内容以后

1. 修改 `docs/data` 里的数据，或者 `docs` 里的代码。
2. 运行 `node tools/build.js`。数据有问题时它会列出来，并且不生成新版本。
3. 在电脑上预览：运行 `python -m http.server 8766 --bind 127.0.0.1 --directory docs`，然后打开 http://127.0.0.1:8766/
4. 提交并推送以后，手机上的 App 下次联网打开时，顶部会提示“有新版本”。
